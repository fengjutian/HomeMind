# 智能家居接入指南（小米 / 华为 / 其他厂商）

HomeMind **不直接连接厂商**。它读取你已经拥有的智能家居系统（Home Assistant
或 MQTT broker）的状态，并且只通过 Family Transaction 写回。

这份文档说明为什么这样设计，以及具体怎么接。

## 1. 为什么没有「一键接入小米」

接入一个厂商的设备，技术上有三条路：

| 方式 | 说明 | 本项目是否采用 |
|------|------|----------------|
| 厂商官方开放平台 | 需要申请开发者资质、OAuth scope、账号注销流程 | 本版本未申请 |
| 抓包 / 逆向私有协议 | 提取 token、模拟官方 App 登录 | **明确禁止** |
| 复用 Home Assistant | 设备先进 HA，HomeMind 再读 HA | ✅ **唯一支持路径** |

第二种的代价不只是技术风险：它意味着 HomeMind 持有的凭据随时可能因厂商
单方面变更而失效，且家庭的设备控制权建立在一个随时可能被收回的通道上。
第一种的门槛是商务与资质问题，不是写几行代码能绕过的。

所以：**你家里本来就有小米生态，请先让 Home Assistant 认识这些设备，
然后把 Home Assistant 接到 HomeMind。** HomeMind 全程不会看到你的小米
账号或华为账号密码。

## 2. 接入步骤

### 2.1 让 Home Assistant 认识你的设备

1. 在 Home Assistant 中安装对应厂商的官方集成：
   - 小米：官方 **Xiaomi Home** 集成，或通过 **Matter** 接入
   - 华为 / 鸿蒙智联：优先使用 **Matter**；若设备已被其他桥接软件接管，
     那个软件同样可以作为 HA 的一个来源
2. 在 HA 的「设置 → 设备与服务」中确认设备状态正常、可以控制。
3. 记下 HA 的地址与 **长期访问令牌**（HA 头像 → 安全 → 长期访问令牌）。

### 2.2 把 Home Assistant 接到 HomeMind

1. HomeMind → 家庭设置 → 智能家居 → 新增接入方。
2. 种类选择 **Home Assistant**，填写地址与令牌。
3. 令牌先存入加密凭据库——接入方表里**只保存一个引用名**，不保存明文。
4. 点击「同步实体」。

完成后，设备会按其**物理设备**聚合显示：一盏灯的亮度、功率等多个实体
合并为一台设备，而不是散落成多行。

## 3. 界面上会看到什么

每个设备会显示：

- **来源**：Home Assistant / Matter / MQTT
- **房间、型号、厂商、固件**
- **能力**：开关、亮度、色温、空调、传感器、窗帘、扫地机、净化器……
- **可用命令**：只有文档化的命令会列出来

来源**只用于展示**。它不会改变任何权限——一盏灯的权限取决于它的域，
与它来自小米、华为还是 Philips 无关。厂商换个营销名，也不会改变设备能做什么。

## 4. 哪些设备可写，哪些只读

本版本的写权限**只由设备域决定**：

| 风险级别 | 域 | 行为 |
|----------|----|------|
| 低 | light / switch / input_boolean / scene | 按家庭策略，可能无需审批 |
| 中 | vacuum | 启动 / 暂停 / 回充，**始终需要审批** |
| 高 | climate / cover / fan / humidifier | **始终需要审批** |
| 禁止 | lock / camera / alarm_control_panel / sensor / binary_sensor | **完全只读** |
| 禁止 | 任何尚未分类的新域 | **默认只读**（不会因为"不认识"就变成可写） |

扫地机器人的地图、摄像头、定点清扫**不在命令目录中**——一个在家里移动的
摄像头不交给 Agent。门锁、摄像头、安防面板本版本只读：把入户门交给一个
LLM 助手不是一个合理的决定，这类设备需要单独的安全评审。

## 5. 常见问题

**设备没出现在列表里。**
先确认它在 HA 里能正常控制。HA 能看到但 HomeMind 不同步，通常是令牌权限
不足（令牌需要能读 `/api/states`），或接入方被禁用。

**设备改名后变成了新设备。**
不会。HomeMind 用 HA 自己的 `device_id` 作为设备身份，改显示名不会产生
新设备，HA 换了实体 id 也不会。

**设备从 HA 删掉了，HomeMind 里还在。**
下次同步会自动清理。如果一直不消失，检查「接入方未连接」状态——连接断开时
不会执行删除，避免一次网络抖动清空整张设备表。

**状态更新有延迟。**
HomeMind 通过 HA WebSocket 接收增量更新，并在每次重连后做一次全量校准。
如果延迟明显，检查 HA 与 HomeMind 之间的网络。

**能用 Home Assistant 的哪些功能？**
只读状态，以及上表中列出的命令。Home Assistant 本身有几千个 service，
HomeMind **不会**把它们开放给 Agent——Agent 只能从上面的目录里选命令。
