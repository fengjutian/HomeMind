常见问题

开始之前，
你可能想知道。

HomeMind 需要购买专用硬件吗？+

不需要。你可以部署在 Windows、macOS 或 Linux 设备上，也可以使用桌面客户端。具体资源需求取决于你选择的模型和功能。

一定要在本地运行大模型吗？+

不一定。HomeMind 支持接入主流 LLM 服务，也可以连接本地 Ollama。你可以按隐私、效果和成本选择适合自己的组合。

家人之间的内容会互相看到吗？+

每位成员拥有独立账号、助手和权限边界；需要共同使用的知识与能力可以在实例内按规则共享。

可以连接哪些设备和服务？+

可通过 Home Assistant 连接智能家居，通过 Connector、插件和 MCP 扩展外部服务，并可从网页、桌面与常用聊天工具使用。
